## Full description

DataAI ETL Spark Libraries provide a Java 17 SDK for normalization, stable
record keys, profiling, declarative validation, clean/rejected routing, quality
findings, grouped analytics, regression, time-series analysis, anomaly and
drift detection, Pareto, cohort and funnel analysis, market models, geographic
readiness, iterative matrix balancing, data dictionaries, chart
recommendations, alerts, and deterministic local narratives.

The libraries execute in the customer's Spark runtime. The customer controls
data sources, destinations, credentials, job scheduling, cluster networking,
write modes, retention, monitoring, and governance. DataAI does not require a
hosted processing service, telemetry, or customer-data transmission.

Spark and Hadoop are provided by the customer runtime and are not bundled in
the DataAI JARs. The evaluation package contains fictional configuration data
and reviewer source materials.
