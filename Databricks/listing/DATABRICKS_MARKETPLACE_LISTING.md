## Detailed description

DataAI ETL gives data engineering, governance, and analytics teams a reusable
Java/Spark library that executes directly inside their Databricks pipelines.
It provides normalization, profiling, declarative validation, automatic data
quality diagnostics, analytics, time-series calculations, business and market
analysis, map readiness, iterative matrix balancing, chart recommendations,
alerts, data dictionaries, and deterministic narratives.

Customers retain control of their Spark DataFrames, Unity Catalog objects,
compute, identity, networking, scheduling, persistence, output formats, table
names, permissions, and orchestration. DataAI returns DataFrames and small
metadata records; writes occur only when customer-authored code explicitly
requests them.

The evaluation package includes fictional sample data, importable notebooks,
documentation, integrity checks, and Java 17 / Spark 3.5 / Scala 2.12
evaluation artifacts. The examples demonstrate quality routing, analytical and
market summaries, matrix balancing with convergence metadata, and optional
governed Delta outputs for BI tools.

DataAI ETL is proprietary, source-available evaluation software from Yanbor LLC, built with open-source technologies including Apache Spark.

## Business outcomes

- Add repeatable data-quality checks to existing Databricks jobs.
- Route accepted and rejected records with traceable findings.
- Standardize analytical and market calculations across pipelines.
- Balance matrix data against row and column control totals.
- Publish governed result tables for Databricks SQL, Power BI, or Tableau.
- Keep sensitive customer data inside the customer's Databricks environment.

- Unity Catalog-enabled Databricks workspace
- Databricks Runtime validated by the customer against Java 17, Spark 3.5.x,
