# DataAI runtime-neutral specification

DataAI ETL is proprietary, source-available evaluation software from Yanbor LLC, built with open-source technologies including Apache Spark.

This directory will contain canonical rule definitions, result schemas, input
fixtures, and expected outputs shared by the .NET, Spark, and Python engines.

The initial Spark implementation establishes the first executable contracts.
Before a second runtime is implemented, these contracts will be extracted into
versioned JSON schemas and golden fixtures here.
